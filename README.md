# Avengers: Doomsday

Landing page conceitual inspirada em **Vingadores: Doomsday**, desenvolvida como projeto de estudo e portfólio, com foco em desenvolvimento front-end, animações e storytelling visual.

## Sobre o projeto

A proposta é criar uma experiência cinematográfica que apresente o universo de Vingadores: Doomsday por meio de uma interface imersiva, transições visuais e animações sincronizadas com a navegação do usuário.

## Seções

- **Hero:** apresentação cinematográfica do Doutor Destino.
- **Introdução:** apresentação do universo e do filme.
- **Trailer:** exibição do trailer.
- **Elenco:** apresentação dos personagens e núcleos.
- **Linha do tempo:** acontecimentos que conduzem a Vingadores: Ultimato e Vingadores: Doomsday.
- **Encerramento:** conclusão visual e créditos do projeto.
